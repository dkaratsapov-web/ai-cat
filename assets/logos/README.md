# Логотипы платформ

Источник: Яндекс Директ — официальный медиакит Яндекс Рекламы (от владельца); остальные — github.com/rafael-mansurov/trace-logos (assets/logos/svgs), PNG 256 px.
Логотипы — товарные знаки их владельцев (Яндекс, VK, Telegram, Meta, MAX). Используются только для
указания на сервис в информационном контексте (как в обзоре), без искажений и без намёка на партнёрство.
