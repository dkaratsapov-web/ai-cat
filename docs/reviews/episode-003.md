# Разбор сценария episode-003 «Почему Яндекс Директ сливает бюджет?»

Шаблон: `assets/templates/scripts/01-direct-budget-v2.yaml`. Скиллы: video-content-strategist (структура Reels),
marketing-psychology (хуки и CTA), content-humanizer (живость текста). Паспорт бренда: `.claude/product-marketing-context.md`.

## Итог

Структура рабочая: хук за 3,5 с, проблема показана на макете, есть решение и мягкий CTA, данные помечены как условные.
Слабые места: хук общий, в ролике три идеи без обещания «трёх», решение в карточке не совпадает с тем, что показано
на макете, у «автоцелей» нет объяснения. Всё это правится **бесплатно** — в сценах s02–s06.

## Проверка по чек-листу

| Пункт | Было | Оценка |
|---|---|---|
| Хук в 0–3 с | «Директ сливает бюджет? Смотрите, куда уходят деньги.» | 🟡 Понятно, но так начинается каждый второй ролик о Директе. Нет конкретики, которая останавливает ленту. |
| Одна мысль на ролик | Мусорные запросы + автоцели + медленный сайт | 🟡 Три идеи. Терпимо, если явно пронумеровать «дыры» — тогда это одна мысль «три дыры». |
| Конкретная польза | Отчёт по запросам раз в неделю, минус-слова, цель на заявку | 🟢 Есть действие, которое можно сделать сегодня. |
| Честность данных | Макет помечен «Пример», есть disclaimer | 🟢 Но в s02 «типичный отчёт» звучит как реальная статистика → лучше «пример». |
| Связность | На макете «обои, игры, чехлы», а в карточке «чужие бренды и «тц»» | 🔴 Зритель видит одно, а совет — про другое. |
| Жаргон | «автоцели», «посадочная» | 🟡 «Автоцели» без пояснения. «Посадочная» → «сайт». |
| Ритм (humanizer) | Длинные фразы с тире подряд в s03–s05 | 🟡 Однотипная интонация. Нужны короткие рубленые фразы. |
| CTA | «Пишите «аудит» в комментариях — посмотрю вашу рекламу.» | 🟢 Мягкий, проверяемый, без обещаний бесплатного. |
| Длина | 60 слов ≈ 24 с речи (+ паузы = 29,4 с) | 🟢 В рамках 20–35 с. |

## Исправленная озвучка (бесплатно: s01 и s07 не трогаем)

Говорящие сцены s01 и s07 синхронизированы с голосом — если поменять в них текст, Kling Avatar придётся генерировать
заново (≈ $0.12–0.16 за сцену). Поэтому в них текст оставлен как есть.

| Сцена | Новая озвучка | Что изменилось |
|---|---|---|
| s01 | Директ сливает бюджет? Смотрите, куда уходят деньги. | без изменений |
| s02 | Пример: магазин айфонов. Открываем отчёт по запросам. | «пример» вместо «типичный», зритель понимает, что смотрит |
| s03 | Обои. Игры. Чехлы для андроида. За каждый клик заплачено — заявок ноль. | рубленый ритм, контраст «айфоны ↔ андроид» |
| s04 | Лечится так: раз в неделю открываете этот отчёт, мусор — в минус-слова. | совет совпадает с макетом |
| s05 | Дыра номер два: в Метрике только автоцели. Это грубый ориентир. Сделайте цель на реальную заявку. | нумерация, пояснение без жаргона |
| s06 | И третья — медленный сайт. Человек уходит раньше, чем увидит кнопку. | «сайт» вместо «посадочная», понятное следствие |
| s07 | Пишите «аудит» в комментариях — посмотрю вашу рекламу. | без изменений |

Итого ≈ 68 слов ≈ 27 с речи. Карточка s04: пункт «Чужие бренды и «тц» — в минус-слова» → «Мусорные запросы — в минус-слова».

Изменения уже внесены в шаблон `01-direct-budget-v2.yaml` — новые ролики по нему получат исправленный текст.

### Как применить к episode-003 (стоимость — копейки за озвучку)

Через веб-панель: в карточках сцен s02–s06 вставить новый текст → «Сохранить текст». Или в PowerShell:

```
studio scene set episode-003 s02 --voiceover "Пример: магазин айфонов. Открываем отчёт по запросам."
studio scene set episode-003 s03 --voiceover "Обои. Игры. Чехлы для андроида. За каждый клик заплачено — заявок ноль."
studio scene set episode-003 s04 --voiceover "Лечится так: раз в неделю открываете этот отчёт, мусор — в минус-слова."
studio scene set episode-003 s05 --voiceover "Дыра номер два: в Метрике только автоцели. Это грубый ориентир. Сделайте цель на реальную заявку."
studio scene set episode-003 s06 --voiceover "И третья — медленный сайт. Человек уходит раньше, чем увидит кнопку."
studio script show episode-003
```

Пункт карточки s04 поменять в `projects\episode-003-...\script\script.yaml` (поле `bullets`).
После `script show` проверить смету: Kling должен показать **$0** (все видео переиспользуются), Яндекс — 5 запросов.
Дальше `studio script approve episode-003` → `studio voice episode-003 --yes` → `studio assemble episode-003` → `studio qa episode-003`.

## Варианты хука для следующих роликов

Все ≤ 9 слов (≈ 3,5 с). Для episode-003 — только если готовы перегенерировать s01 (≈ $0.12–0.16).

1. **Контраст (pattern interrupt):** «Вы продаёте айфоны. А платите за «чехлы для андроида».»
   Конкретная абсурдная деталь из макета — останавливает ленту лучше вопроса.
2. **Открытая петля + число:** «Три дыры, через которые Директ ест бюджет.»
   Обещает структуру, зритель досматривает до третьей. Сочетается с нумерацией в s05–s06.
3. **Страх потери:** «Клики есть, заявок нет? Деньги утекают вот сюда.»
   Говорит языком клиента («клики есть — звонков нет»).

Рекомендация: вариант 2 для серии «Где утекает бюджет», вариант 1 — для роликов с макетом отчёта.

## Чего сознательно не делали

- Скиллы советуют подкреплять хук цифрами («85% смотрят без звука», «удержание падает на 40%»).
  Источников у этих цифр нет — по правилам рубрики в ролики их не берём.
- Обещания результата («сэкономите 30% бюджета») не добавлены: нет данных владельца.
