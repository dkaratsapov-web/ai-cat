# Идеи и решения на будущее (договорённости с владельцем)

## Принято, в работе
- **Кот за компьютером + скрин на мониторе.** Референс: кот у монитора с экраном ровного хромакей-зелёного #00FF00.
  Kling/Seedance анимирует кота, при монтаже на зелёный экран вставляется НАСТОЯЩИЙ скрин (перспектива, блик,
  лапа перед экраном остаётся поверх). Затем «нырок» камеры в монитор → скрин на весь экран (читаемость).
  Клипы «кот у монитора» переиспользуются в разных роликах — повторно не оплачиваются.
  Нужно от владельца: 2–3 кадра по ТЗ для ChatGPT (кот смотрит на экран / показывает лапой / смотрит в камеру).
- **Переходы «круче»:** кот → скрин «пролёт» (zoomin), скрин → скрин «свайп» (smoothleft), к карточке — сдвиг вверх;
  «вылет» панели скрина; рамка подсветки «прорисовывается» слева направо. Черновик кода был, не проверен — доделать.
- **Higgsfield вторым генератором** (Seedance для 1–2 «вау»-сцен), Kling остаётся для Avatar и обычного движения.
  Сначала слепой тест сцены «кот у монитора»: Kling 2.6 (≈ $0.15) против Seedance 2.0 (≈ $0.70). См. INTEGRATIONS.md.
