# Telegram-бот и мини-приложение студии

Владелец пишет задачи в Telegram или в мини-приложении. Работают два агента:
- 🐱 **Claude-продюсер** (Anthropic API) делает задачи в проекте: читает и правит сценарий, собирает ролик,
  запускает QA, смотрит кадры, ищет в базе знаний, присылает файлы.
- 🎬 **Директор** (OpenAI) смотрит работу (кадры сцен, контактный лист ролика, субтитры) и даёт замечания.

**Деньги.** Платные `generate` и `voice` агенты не запускают. Бот присылает смету с кнопками «Утверждаю» и «Отмена»,
команда запускается только после нажатия. Вопросы и ревью директора стоят центы, у них есть дневной лимит
(`config/agents.yaml`).

## Установка (один раз)
1. В `.env`: `TELEGRAM_BOT_TOKEN`, `TELEGRAM_OWNER_ID`, `ANTHROPIC_API_KEY`, `OPENAI_API_KEY`.
2. `pip install -e ".[bot]"`
3. Для мини-приложения нужен туннель Cloudflare: он бесплатный и не требует регистрации:
   `winget install --id Cloudflare.cloudflared`.
   Без туннеля бот работает обычным чатом в Telegram.

## Запуск
`studio bot`, затем в Telegram команда `/start` и кнопка «Открыть студию». Пока окно PowerShell открыто, бот работает.

Команды в чате: `/ep <эпизод>` (выбрать эпизод), `/d вопрос` (сразу директору), `/new` (новый разговор с Claude).

## Настройка агентов
В `config/agents.yaml` задаются имя, эмодзи, характер, модель и глубина размышлений, а также лимиты.

## Безопасность
- Бот отвечает только `TELEGRAM_OWNER_ID`.
- Мини-приложение проверяет подпись Telegram у каждого запроса.
- Агентам недоступны `.env` и `data/`.
- Писать агенты могут только в `script.yaml` и `director_notes.md` эпизода, перед правкой сохраняется копия.
- Ключи вырезаются из логов и ошибок.
