# ТЗ: анимация переходов и музыка (учитывать в следующих версиях)

Утверждено владельцем 2026-10-05. Статус: **запланировано, не реализовано** (кроме отмеченного ✅).

## 1. Переходы

Не ограничиваться обычными склейками. Нужна библиотека переиспользуемых анимированных переходов.
Переходы аккуратные: экспертный ролик не превращать в клиповый монтаж.
**Приоритет — 1–2 фирменных типа переходов на ролик.**

| Переход | Как сделать (план) | Стоимость |
|---|---|---|
| whip-pan | быстрый сдвиг кадра + направленное размытие (FFmpeg: crop/translate + `gblur`/`tmix`), стык на пике размытия | бесплатно |
| zoom-through | наезд в центр A → вылет из центра B (`xfade=zoomin` или свой кадровый рендер) | бесплатно |
| match cut по движению кота | монтажное решение: стык там, где движение лапы/головы в A продолжается в B; разметка точек стыка в сценарии | бесплатно |
| через монитор/экран | хромакей-экран в кадре кота → «нырок» в экран → скрин на весь кадр (см. IDEAS.md) | клип у монитора переиспользуется |
| blur transition | `xfade=hblur` / размытие на стыке | бесплатно |
| speed ramp | ускорение конца клипа A и разгон B (`setpts` по кривой) | бесплатно |
| parallax | сдвиг переднего и заднего плана с разной скоростью; нужна маска кота (сегментация) — сложно | бесплатно, но трудоёмко |
| light leak / glow | наложение светового блика (свой сгенерированный ассет) в режиме screen | бесплатно |
| быстрый push-in / pull-out | короткий зум на последних/первых 0,3 с клипа | бесплатно |
| через объект в кадре | «вайп» объектом (лапа, арка, кружка), заполняющим кадр; лучше — AI-клип перехода | AI-клип |
| смена цифр рейтинга 5→4→3→2→1 | анимированный счётчик-плашка (перекат цифры, ease-in-out) | бесплатно |

**Фирменные переходы кота (3–5 штук, для узнаваемости):**
- через лапу: кот проводит лапой по камере — кадр «смахивается»;
- через экран ноутбука/монитора: нырок в экран;
- через проход между арками в студии: камера проходит в арку → следующая сцена;
- (варианты) пар от кофе заполняет кадр; лупа увеличивается на весь кадр.

Как делать фирменные: AI-клип перехода между двумя кадрами — у Seedance есть `end_image_url`
(первый кадр = конец сцены A, последний = начало сцены B); такие клипы генерируются один раз и переиспользуются.

## 2. Музыка

- современная, технологичная, лёгкая; без навязчивого вокала; не перекрывает речь;
- ✅ автоматическое приглушение под голос (ducking — уже есть в сборке);
- плавные fade-in / fade-out;
- синхронизация смены сцен с битом (поиск долей такта, сдвиг стыков в пределах ±0,2 с без потери синхрона речи);
- пресеты по типам роликов: **экспертный, юмористический, кейс, динамичный, премиальный**;
- версия ролика без музыки — всегда в комплекте публикации;
- только треки с правом коммерческого использования (или собственные, сгенерированные кодом — без вопросов лицензии).

## 3. Архитектура

Отдельные модули, чтобы стиль монтажа менялся без правки основной логики:
- `src/studio/editing/transitions/` — каталог переходов (имя → функция рендера стыка), выбор в сценарии:
  `transition: whip_pan` у сцены или стиль ролика `edit_style: expert` в конфиге;
- `src/studio/editing/music/` — пресеты (`config/music.yaml`: трек, громкость, ducking, fade, bpm),
  поиск битов, выравнивание стыков.

Уже есть основа: переходы xfade по смыслу (черновик), «вылет» панели скриншота, приближения камеры по словам озвучки.
