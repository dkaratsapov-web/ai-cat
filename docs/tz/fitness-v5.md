## Вопросы владельцу
1. Утвердить новые кадры: `studio character approve office_dashboard_point fit_paw_mat fit_present_mirror fit_present_side fit_tablet_mat`
   (остальные новые — по желанию).
2. На новых студийных кадрах на худи белый **самолёт ✈**, а в офисе — бумажный самолётик. Оставляем?
3. На мониторе в s06c видны цифры кабинета рекламы. Это иллюстрация, а не результат кейса, но если цифры
   смущают, выберем другой кадр.

## Порядок
`git pull` → `script load` → `script approve` → `voice` → `script show` (платные только s06c, s07, s13, s13b, s14)
→ `generate` → `assemble` → `assemble --no-music` → `qa` → просмотр владельцем (губы, внешность кота).
